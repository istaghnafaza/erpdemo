SEPS — Alur Transaksi Pembayaran Midtrans Snap

Dokumen untuk review onboarding Midtrans · Merchant: SEPS (Simetri ERP Store) · Website: https://seps.fazagroup.id

Ringkasan produk

SEPS adalah aplikasi SaaS ERP untuk toko bangunan. Pelanggan (owner toko) berlangganan paket berbayar (Basic / Pro / Enterprise) dan membayar melalui Midtrans Snap (QRIS / Virtual Account / e-wallet). Setelah pembayaran sukses, Midtrans mengirim notifikasi webhook ke server SEPS; paket langganan diaktifkan otomatis.

3. Alur transaksi langkah demi langkah (dengan screenshot)

  1. Langkah 1 — Buka situs & login

    Reviewer membuka https://seps.fazagroup.id/login, memasukkan username dan PIN akun uji, lalu klik Masuk.

    Screenshot #1 — Halaman Login SEPS

  2. Langkah 2 — Dashboard & tombol Upgrade

    Setelah login, muncul banner trial / kunci modul. Klik Upgrade (banner atas) atau Upgrade Paket (sidebar bawah) untuk membuka sheet upgrade.

    Screenshot #2 — Dashboard + tombol Upgrade (banner & sidebar)

  3. Langkah 3 — Pilih paket & bayar

    Sheet Upgrade paket muncul. Pilih siklus Bulanan/Tahunan dan paket (Basic / Pro / Enterprise). Klik nama paket untuk detail fitur di halaman harga, atau tekan Bayar … untuk membuka Midtrans Snap.

    Screenshot #3 — Sheet Upgrade paket (pilih plan + Bayar Pro)

  4. Langkah 4 — Midtrans Snap: pilih metode bayar

    Popup Midtrans Snap menampilkan nominal (contoh Rp850.000 untuk Pro bulanan), order ID, dan daftar metode: GoPay/QRIS, Virtual Account, kartu, ShopeePay.

    Screenshot #4 — Midtrans Snap — daftar metode pembayaran

  5. Langkah 5 — Bayar via Virtual Account (contoh BCA)

    Reviewer memilih Virtual Account BCA. Midtrans menampilkan nomor VA yang harus dibayar. Setelah settlement, webhook mengaktifkan paket di SEPS secara otomatis.

    Screenshot #5 — Midtrans — pembayaran BCA Virtual Account

4. Diagram alur (ringkas)

User (Owner)
  → Login SEPS (username + PIN)
  → Dashboard → klik Upgrade / Upgrade Paket
  → Sheet Upgrade → pilih paket → Bayar
  → Midtrans Snap (pilih QRIS / VA / e-wallet)
  → Selesaikan pembayaran di Midtrans
  → Webhook → SEPS /api/midtrans/notification
  → Verifikasi signature + aktivasi plan
  → User akses fitur sesuai paket
