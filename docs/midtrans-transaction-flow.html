SEPS — Alur Transaksi Pembayaran Midtrans Snap

Dokumen untuk review onboarding Midtrans · Merchant: SEPS (Simetri ERP Store) · Website: https://seps.fazagroup.id

Ringkasan produk

SEPS adalah aplikasi SaaS ERP untuk toko bangunan. Pelanggan (owner toko) berlangganan paket berbayar (Basic / Pro / Enterprise) dan membayar melalui Midtrans Snap (QRIS / Virtual Account / e-wallet). Setelah pembayaran sukses, Midtrans mengirim notifikasi webhook ke server SEPS; paket langganan diaktifkan otomatis.

3. Alur transaksi langkah demi langkah

  1. Langkah 1 — Buka situs & login

    Reviewer membuka https://seps.fazagroup.id/login, memasukkan email/username dan password akun uji, lalu masuk ke dashboard toko.

    TEMPAT SCREENSHOT #1
    Halaman Login SEPS

  2. Langkah 2 — Masuk dashboard / halaman pricing

    Setelah login, reviewer melihat banner paket / akun trial. Klik Upgrade di banner, atau buka https://seps.fazagroup.id/pricing lalu pilih paket.

    TEMPAT SCREENSHOT #2
    Dashboard + banner Upgrade / halaman Pricing

  3. Langkah 3 — Pilih paket & siklus tagihan

    Sheet Upgrade paket muncul. Pilih siklus Bulanan atau Tahunan, lalu pilih salah satu: Basic / Pro / Enterprise. Tekan tombol Bayar ….

    TEMPAT SCREENSHOT #3
    Sheet Upgrade paket (pilih plan + Bayar)

  4. Langkah 4 — Midtrans Snap checkout

    Sistem memanggil API Midtrans Snap (server-side) dan membuka popup Snap. Reviewer memilih metode pembayaran (QRIS / VA / GoPay) dan menyelesaikan pembayaran sesuai instruksi Midtrans (sandbox atau production sesuai environment merchant).

    TEMPAT SCREENSHOT #4
    Popup Midtrans Snap — pilih metode bayar
    TEMPAT SCREENSHOT #5
    Halaman pembayaran Midtrans (QRIS/VA/e-wallet)

4. Diagram alur (ringkas)

User (Owner)
  → Login SEPS
  → Pilih paket (Upgrade / Pricing)
  → Backend SEPS: create Snap transaction (order_id + amount)
  → Midtrans Snap UI (bayar QRIS/VA/e-wallet)
  → Midtrans webhook → SEPS /api/midtrans/notification
  → Verifikasi signature + aktivasi plan
  → User akses fitur sesuai paket
